# Historical Documentation Archive

This directory contains preserved historical material. Nothing under
`docs/archive/` is an active product requirement, AI instruction, operator
procedure, or source-of-truth owner. Current navigation starts from the root
README, the user guide, and `docs/project/DOC_OWNERSHIP.md`.

## Preserved repository documents

- `project-requirements-baseline.md` is the former mixed product aggregate. Its
  valid stable material was extracted into Project State and specialist owners;
  superseded mobile and identity clauses remain only as historical evidence.
- `subject-sync.md` is the early 2026-04 TV-only sync procedure. It is retained
  for rationale/history and must not be used for current sync behavior.
- `data-reset.md` is the early 2026-04 recovery/audit procedure. Its durable
  safety principle—move data to a recoverable backup rather than delete it—is
  now carried by `AGENTS.md`; the old business procedure is historical.

## External migration artifacts

manifests are transition evidence, not repository requirements. The foreign old
