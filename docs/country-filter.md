# 日本范围与结构化证据过滤

第一版只收录日本 Anime 的 TV 与剧场版。候选先按 canonical `air_date` 和媒体形式
判断是否属于请求季度，再判断日本性；因此搜索回看的非目标季度 Movie 不会产生日本性
REVIEW 或错误的 `assign` 指引。Search 的 7 天回看只服务 TV 边界候选，Movie 仍由自然
季度严格归属。

## 日本性判定

规则只使用确定的结构化字段，不使用 AI、模糊匹配、标题、简介、普通社区标签、语言、
staff 或公司推断国家。

1. 优先读取已核验的 `Subject.meta_tags` 公共地区 token；当前支持的精确 token 为
   `日本`、`Japan`、`中国`、`美国`、`韩国`、`法国`。`欧美` 是宽泛标签，单独不能作出结论；
2. 再读取 Infobox 的精确 key：`制片国家/地区`、`国家/地区`、`制片国家`、`地区`；
3. 值先作 Unicode NFKC 与 trim，再仅按 `/`、`／`、`、`、`,`、`，`、`;`、`；`、`|`、`｜`
   和 `・` 分隔。`日本` 与 `Japan` 是同一精确别名；未知 token 不会被翻译或模糊归类。

同一个结构化来源中的 `{日本, 中国}` 等精确合拍证据会判为日本性包含；不同来源只要
都包含日本也相容。一个来源为 `{日本}`、另一个独立来源只有 `{美国}` 时，属于真实
结构化冲突并保留 REVIEW。所有精确来源都明确为非日本时才排除；只有宽泛标签、缺失
字段或无法安全解析时保持未决。

2025-01 的受控审计确认，公共 `meta_tags` 中的精确 `法国` 在两个已知法国作品上与
正典身份一致，因此加入精确负向 token；`欧美` 仍没有被提升为国家证据，也不能取消
精确日本证据。当前本地事实库没有保存上述四个 Infobox 国家 key 的样本行，因此没有
证据支持删除或扩大通用 `地区` key；它继续只按精确 key/value 合同作为 fallback。

未决或冲突日本性 REVIEW 可由使用者明确裁决：

```text
bgmb classify BGM_ID --japanese
bgmb classify BGM_ID --non-japanese
bgmb classify BGM_ID --clear
```

决定写入独立的 `config/japanese-overrides.toml`，不改变媒体形式、季度规则或继续
播出事实。`--clear` 恢复裁决前保存的自动证据；若非日本裁决已移除本地事实，需再次
sync 才会重新评估该作品。

## 结果支配与审计

可靠日期已经超过 7 天且 `rating_count < 30` 时，未决或冲突的日本性分支无论最终会被
判为日本还是非日本，都不可能进入公开档案：前者会被低评分规则排除，后者会被范围规则
排除。系统可记录 `outcome_dominated_low_rating` 自动排除，但仍保留原始日本性为
`UNRESOLVED`，不把它伪装成已解决。缺少日期、评分人数或仍可能纳入档案的情况不会走
这个快捷路径。

同步和本地裁决审计记录 subject ID、安全标题、最终决策、证据来源、结构化 token 和
REVIEW 原因；原始 API 响应、授权信息和私有工作区数据不进入仓库。

## 剧场 Movie 范围

canonical `platform=剧场版` 不是“普通院线上映”的充分条件。正典 Infobox
`其他=游乐设施电影` 或 `其他=プラネタリウム上映作品` 会得到
`non_theatrical_special_venue` 硬拒绝，不进入第一版 Movie 范围。该门只接受这两个
已核验的精确结构化值；标题、简介、官网域名或 URL 路径都不是运行时证据。若已核实的
个案缺少可复用结构化字段，使用精确人工 `excluded_subject_ids`，不新增标题启发式。

旧 `auto_excluded_subject_ids` 在刷新后若被新证据判为非日本或非院线特殊场所，会在
同一事务中移除，并在同步报告的 `auto_reconciled` 中单列；这类硬拒绝不会继续伪装成
低评分自动排除。
