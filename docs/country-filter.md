# 日本 TV 自动范围过滤

第一版对 Bangumi `GET /v0/subjects/{id}` 的候选执行确定性、完全自动的国家/地区分类；
不需要逐条人工审核。规则不使用 AI、模糊匹配、标题、简介、语言或公司推断。

## 判定顺序

1. 优先读取已核验的 `Subject.meta_tags` 公共地区证据；
2. 缺失公共地区证据时，严格回退到 Infobox key：`制片国家/地区` 与 `国家/地区`；
3. 值先作 Unicode NFKC 与 trim，再仅以 `/`、`／`、`、`、`,`、`，`、`;`、`；` 和 `・` 分隔。
   精确 token 为 `日本` 或 `Japan` 时收录，明确非日本值时排除，同一一致值中的合拍国家允许；
4. 日本与其它地区并存、两类结构化 evidence 冲突或没有 evidence 时进入 REVIEW。

没有 TV default admission，也不使用普通社区标签、标题、简介、语言、公司或 AI 推断国家。
`日本风`、`日本語`、未知分隔符和任意近似词都不是证据。

## 审计

同步审计记录 subject ID、安全标题、最终决策、证据来源、结构化 token 和 REVIEW 原因。
结构化字段缺失、无法解析或冲突不会被默认放行；只有明确 accepted 的候选进入公开事实库。
