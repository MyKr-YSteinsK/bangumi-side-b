# 日本制作范围过滤

第一版只从 Bangumi `GET /v0/subjects/{id}` 的结构化 `infobox` 读取国家证据。
已在 2026-07-30 对公开响应核验两个精确 key：`制片国家/地区` 与
`国家/地区`。最小化 fixture 仅保存判断所需字段：日本（157900）、非日本
（113162）、日本/法国合拍（145120）及缺失字段（659440）；不保存简介、评论或完整响应。

值先作 Unicode NFKC 和 trim，再仅以 `/`、`／`、`、`、`,`、`，`、`;`、`；`
和 `・` 分隔。token 必须精确等于 `日本` 或 `Japan` 才能收录；同一一致值中的
其他国家不影响收录。`日本风`、`日本語`、未知分隔符及无法解析值都会排除。

所有已验证 key 的非空值必须产生同一个 token 集。没有值记为 missing，无法解析记为
unparseable，token 集不同记为 conflict；三种情况均不收录，也不会以标题、简介、语言、
公司或社区标签补推断。同步审计只记录 subject ID、安全标题、决策、key、规范化 token
和短原因。
